# Icon and mark sources

- **UI icons**: `lucide-react` 1.x (ISC). One stroke weight (1.75) applied globally.
- **Brand glyphs** (Apple Pay, Google Pay, Klarna, Stripe, Meilisearch, Cloudinary, Resend, DPD, DHL, MapLibre, OpenStreetMap): `simple-icons` 16.x (icon artwork CC0). Cropped to their real extent and drawn without a frame in the brand colour (ink where the brand colour is too light to read).
- **Card and PayPal logos** (Visa, Mastercard, American Express, PayPal): the `payment-icons` package, "single" set (MPL-2.0). Files are embedded unmodified apart from removing editor metadata (`apps/portal/scripts/gen-marks.py`). If you modify these files, MPL-2.0 requires the changed files to stay under MPL-2.0.
- Provider-owned artwork (no generated logos): Link, Clearpay, ShipBob and Ideal Postcodes are stored under `apps/portal/public/brands/` as original SVG marks extracted from provider pages. Royal Mail, ShipStation, Printful, Printify, Postcodes.io and GS1 UK reference their official website assets in `apps/portal/src/lib/brands.ts`. These external references are interim: vendor verified copies locally before production for reliability and CSP/privacy; do not modify trademark geometry or imply endorsement. Generic UI icons remain for unbranded functionality only.
- Source pages: https://stripe.com/gb/payments/onelink ; https://www.clearpay.co.uk/en-GB/for-retailers/resources/marketing/logos ; https://www.shipbob.com/ ; https://ideal-postcodes.co.uk/ ; https://www.royalmail.com/ ; https://www.shipstation.com/ ; https://www.printful.com/ca/brand-assets ; https://printify.com/press-kit/ ; https://postcodes.io/ ; https://www.gs1uk.org/ . See the registry for exact externally referenced asset URLs.
- Trademarks belong to their owners. These marks identify methods on the merchant's own screens; shoppers see Stripe's official marks in the Payment Element. Apple Pay, Visa and Mastercard have their own brand-usage rules for any shopper-facing use.
